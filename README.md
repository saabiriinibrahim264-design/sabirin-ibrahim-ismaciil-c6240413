​Description:
Demonstrates Object-Oriented Programming (OOP) concepts in Java, including Encapsulation using private fields with getters and setters, Static variables for shared data (UNIVERSITY_NAME), and input validation for student attributes such as Age and GPA.
​Question 2: Encapsulated Bank Account
​Description:
Demonstrates Data Encapsulation by securing the bank account balance as a private field. It provides controlled access through public methods like deposit() and withdraw(), incorporating validations to prevent invalid transactions or insufficient funds.
